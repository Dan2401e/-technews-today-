# 🚀 TechNews Today

Portal de notícias sobre tecnologia desenvolvido como atividade prática de **HTML e CSS**, com foco na aplicação de conceitos modernos de layout, estilização e responsividade.

## 📋 Sobre o projeto

O **TechNews Today** é uma página web que apresenta novidades do mundo da tecnologia em uma interface moderna e responsiva.

O projeto foi desenvolvido utilizando apenas **HTML e CSS**, sem frameworks e sem JavaScript, colocando em prática recursos como:

* 🧊 Glassmorphism
* 🎨 Gradientes
* 📐 CSS Grid
* 📌 `position: sticky`
* 📱 Design responsivo
* 📰 Estrutura semântica HTML
* 🎥 Incorporação de vídeo
* 📧 Formulário de inscrição

## 🎯 Objetivo da atividade

O objetivo desta atividade é desenvolver um portal moderno utilizando recursos de **HTML e CSS**, demonstrando conhecimentos de estruturação de páginas, organização visual e responsividade.

Também foi proposto o uso de recursos modernos de CSS, mantendo o projeto simples e sem a utilização de frameworks ou JavaScript.

## ✨ Principais recursos

### 🧊 Glassmorphism

O cabeçalho utiliza `backdrop-filter: blur()` combinado com transparência para criar um efeito de vidro fosco.

### 🌈 Texto com gradiente

O título principal utiliza um gradiente aplicado diretamente ao texto através de recursos do CSS.

### 📐 CSS Grid

O conteúdo principal utiliza **CSS Grid** para organizar os elementos de forma estruturada em diferentes tamanhos de tela.

### 📌 Header fixo

O cabeçalho utiliza:

```css
position: sticky;
```

Dessa forma, ele permanece visível durante a rolagem da página.

### 📱 Responsividade

Uma **Media Query** é utilizada para adaptar o layout para telas maiores, permitindo que o conteúdo seja organizado em colunas.

### 🎥 Vídeo

O portal possui um vídeo incorporado utilizando um elemento `<iframe>`.

### 📧 Formulário

A página também conta com um formulário de inscrição contendo:

* Campo de e-mail;
* Seleção de curso;
* Aceite dos termos;
* Botão de inscrição.

## ▶️ Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. O arquivo CSS será carregado automaticamente através do `<link>` presente no HTML.

> **Importante:** o nome do arquivo CSS deve permanecer exatamente como `style.css`, conforme definido no projeto.
